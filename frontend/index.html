A two-player field journal

Two farmers, three languages, one duel a day.

You each get the identical card set for HTML, CSS and JavaScript, and you play it whenever suits you. At the end of the day a winner is declared for each language. Underneath sits real spaced repetition and a story for every rule that keeps slipping.

Why the same cards? Fairness. Both sets come from the same sha256(date + language) seed, so neither of you can play a kinder deck than the other.

How a day works

1 · The set

20 cards per language. Same cards, same order, both of you.

Drawn from everything you have unlocked so far, so the deck keeps moving.

2 · The recall

You type the answer. No multiple choice, one retry.

100 first try, 60 after a retry, 30 with the hint, 0 for a miss. The attempt count lives on the server.

3 · The settle

A winner per language, every day.

Missed a card? The story that explains it opens right at the paragraph you needed.
